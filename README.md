# Arduino Temperature Monitoring System

An Arduino-based temperature monitoring project using the LM35 analog temperature sensor.

## Hardware Components
- Arduino Uno
- LM35 Temperature Sensor
- Breadboard
- Jumper Wires

## Technologies
- Embedded C++
- Arduino IDE
- Analog-to-Digital Conversion (ADC)
- Serial Communication

## Features
- Real-time temperature measurement
- Analog sensor data acquisition
- Temperature calculation
- Serial Monitor output

## Learning Outcomes
- Understanding ADC
- Reading analog sensor values
- Voltage conversion
- Basic embedded programming
